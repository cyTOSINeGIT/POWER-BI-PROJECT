# Project Overview

This project focused on analysing network outage performance using Microsoft Power BI to provide a consolidated view of outage incidents, service-level performance, resolution times, and detection times across the network.

The analysis brought together outage incident, SLA performance, site, vendor, and root-cause information to examine key operational performance indicators and identify patterns affecting network reliability and service delivery.

The Power BI report was structured around four key performance areas: Overall Network Performance, SLA, Mean Time to Repair (MTTR), and Mean Time to Detect (MTTD).

## Network Outage Analysis

The project analysed network outage incidents to understand the scale and distribution of outages across different sites and operational categories.

The overview dashboard provided high-level KPIs and visualisations covering outage incidents, site performance, root causes, and service-level metrics. This created a consolidated view of network reliability and helped highlight areas requiring further investigation.

## SLA Performance

The analysis examined Service Level Agreement (SLA) performance across the network.

SLA performance was analysed by site, vendor, root-cause category, and other operational dimensions to identify variations in service performance and areas where SLA requirements may not have been consistently achieved.

## Mean Time to Repair (MTTR)

The project analysed Mean Time to Repair to understand how quickly network issues were resolved after an outage occurred.

MTTR performance was examined across sites, vendors, root-cause categories, and over time. The analysis helped provide visibility into differences in resolution performance and potential operational bottlenecks.

## Mean Time to Detect (MTTD)

The project also analysed Mean Time to Detect to evaluate how quickly network incidents were identified.

MTTD was examined by site type, root-cause category, severity level, vendor, and monthly trends. This provided insight into detection performance and helped identify areas where faster incident identification could improve overall network response.

## Power BI Dashboard

An interactive Power BI dashboard was developed to bring the analysis together into a clear reporting environment.

The dashboard included KPI cards, bar charts, column charts, line charts, area charts, funnel visualisations, and interactive navigation elements to allow users to explore network performance from different perspectives.

## Project Outcome

The project provided a structured view of network outage performance and operational efficiency, allowing key measures such as SLA, MTTR, and MTTD to be examined across different sites, vendors, root causes, severity levels, and time periods.

Overall, the project demonstrated practical skills in Power BI dashboard development, KPI analysis, operational performance reporting, data modelling, and interactive data visualisation, with a focus on improving visibility into network reliability and outage management.
